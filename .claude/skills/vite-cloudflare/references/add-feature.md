# Add Feature

Orchestrate parallel sub-agents to add a complete feature with API, page, and component.

## CRITICAL: Parallel Execution Required

This command MUST spawn multiple sub-agents in PARALLEL using a single message with multiple Task tool calls.

## Workflow

Parse `$ARGUMENTS` to get FEATURE_NAME, then spawn ALL of these Task tools in a SINGLE message:

1. **api-generator add-route** (sonnet) -- Create {FEATURE_NAME} route with CRUD
2. **api-generator add-schema** (sonnet) -- Create Zod schemas for {FEATURE_NAME}
3. **api-generator add-service** (sonnet) -- Create service layer for {FEATURE_NAME}
4. **vite-cloudflare page** (haiku) -- Create {FEATURE_NAME} page with --with-components
5. **vite-cloudflare component** (haiku) -- Create {FEATURE_NAME}Card component

## API Delegation

API generation is handled by the `api-generator` skill, NOT by vite-cloudflare. This ensures:
- Proper service layer (routes are thin, services contain business logic)
- Drizzle ORM for database access (not raw D1 prepare/bind)
- Zod schemas as single source of truth for validation
- Production patterns from `.claude/assets/best-practices/hono-cf-workers/`

## Example Execution

For `/vite-cloudflare add-feature users`:

```
// Spawn ALL in a SINGLE message:

Task(model: "sonnet", prompt: "Read .claude/skills/api-generator/references/routes.md and .claude/assets/best-practices/hono-cf-workers/routes.md. Create users route with CRUD: GET /users, GET /users/:id, POST /users, PUT /users/:id, DELETE /users/:id.")

Task(model: "sonnet", prompt: "Read .claude/skills/api-generator/references/schemas.md. Create Zod schemas for users resource: createUserSchema, updateUserSchema, listUsersQuerySchema.")

Task(model: "sonnet", prompt: "Read .claude/skills/api-generator/references/services.md. Create UserService with list, getById, create, update, delete methods using Drizzle ORM.")

Task(model: "haiku", prompt: "Read .claude/skills/vite-cloudflare/references/page.md. Create Users page at src/client/pages/Users/ with --with-components. Include _components/, _hooks/, _types/.")

Task(model: "haiku", prompt: "Read .claude/skills/vite-cloudflare/references/component.md. Create UserCard component at src/client/pages/Users/_components/. BEM styling, display user name and email.")
```

## Generated Structure

```
src/
├── client/pages/{Feature}/
│   ├── {Feature}Page.tsx
│   ├── {Feature}Page.css
│   ├── _components/

│   │   ├── {Feature}Content.tsx
│   │   ├── {Feature}Card.tsx
│   │   └── index.ts
│   ├── _hooks/
│   │   ├── use{Feature}.ts
│   │   └── index.ts
│   ├── _types/
│   │   ├── {feature}.ts
│   │   └── index.ts
│   └── _utils/
│       └── index.ts
└── worker/
    ├── routes/{feature}.ts      # Generated by api-generator
    ├── schemas/{feature}.ts     # Generated by api-generator
    └── services/{feature}.service.ts  # Generated by api-generator
```

## Output

After all agents complete, summarize:

```
## Feature Added

**Name**: {FEATURE_NAME}
**Route**: /{feature-name}
**API**: /api/{feature-name}

### Sub-Agents Spawned (Parallel)
1. api-generator add-route - CRUD endpoints (best practices)
2. api-generator add-schema - Zod validation schemas
3. api-generator add-service - Service layer with Drizzle ORM
4. vite-cloudflare page - Page with co-location
5. vite-cloudflare component - Card component

### Integration Required
1. Add route to src/worker/routes/index.ts:
   \`\`\`typescript
   import {feature} from "./{feature}";
   routes.route("/{feature}", {feature});
   \`\`\`

2. Add page to src/client/router.tsx:
   \`\`\`typescript
   import { {Feature}Page } from "./pages/{Feature}/{Feature}Page";
   { path: "{feature}", element: <{Feature}Page /> }
   \`\`\`

3. Create migration:
   \`\`\`bash
   npm run db:generate
   npm run db:migrate:local
   \`\`\`
```
