# Style: brutalist

Raw, bold, high-contrast design with oversized typography, exposed structure, and intentional roughness. Anti-polish aesthetic.

## Vibe

Unapologetic, loud, structural. Oversized monospace or grotesque type dominates. High contrast black/white with occasional neon accents. Visible borders and grids. No shadows, no gradients — just raw structure.

## Fonts

Monospace or grotesque sans-serif. Oversized, unapologetic.

```css
--font-sans: 'Space Grotesk', 'Arial Black', Helvetica, sans-serif;
--font-mono: 'Space Mono', 'Courier New', monospace;
```

## Key Patterns

- **Oversized type** — Hero headings 6-10rem, tight letter-spacing
- **Thick borders** — 2-4px solid black borders everywhere
- **No shadows** — Flat design, no elevation
- **No rounded corners** — `border-radius: 0` or very minimal
- **Grid exposed** — Visible CSS grid structure
- **Uppercase labels** — Bold, tracked-out uppercase text
- **Harsh hover states** — Color inversion, not subtle transitions
- **Monospace data** — All numbers and data in monospace
