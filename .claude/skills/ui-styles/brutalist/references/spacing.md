# Spacing — brutalist

## Scale

```css
:root {
  --space-xs: 4px;
  --space-sm: 8px;
  --space-md: 16px;
  --space-lg: 24px;
  --space-xl: 32px;
  --space-2xl: 48px;
  --space-3xl: 64px;
  --space-4xl: 96px;
}
```

## Border Radius

None or minimal.

```css
:root {
  --radius-none: 0;
  --radius-sm: 2px;
}
```

## Layout

```css
:root {
  --max-width: 1200px;
  --wrapper-padding: 24px;
}
```

## Breakpoints

| Name | Value |
|------|-------|
| Mobile | `max-width: 480px` |
| Tablet | `min-width: 640px` |
| Desktop | `min-width: 1024px` |
