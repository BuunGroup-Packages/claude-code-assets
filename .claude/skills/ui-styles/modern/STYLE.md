# Style: modern

Clean SaaS landing style with alternating light/dark sections, photo-heavy card layouts, lime/yellow-green CTAs, and a hospitality-forward aesthetic. Inspired by me&u.

## Vibe

Fresh, inviting, content-forward. Alternating cream-white and deep forest-green sections create visual rhythm. Large photography dominates cards. Typography is clean system fonts with generous sizing. CTAs pop with lime-green against dark backgrounds.

## Palette Preview

| Role | Value | Description |
|------|-------|-------------|
| Background (light) | `#ffffff` | Clean white |
| Background (dark) | `#1a2e1a` | Deep forest green |
| Surface | `#f5f5f0` | Warm off-white |
| Surface (dark) | `#243524` | Lighter forest |
| Accent CTA | `#c8ee44` | Lime/yellow-green |
| Primary | `#1a2e1a` | Dark green (text, buttons) |
| Text | `#1a1a1a` | Near-black |
| Text muted | `#666666` | Mid-gray |
| Text on dark | `rgba(255,255,255,0.9)` | Light on dark sections |

## Fonts

System font stack — no custom web fonts. Fast loading, native feel.

```css
--font-sans: system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
```

## Key Patterns

- **Alternating sections** — Light (`#fff`) and dark (`#1a2e1a`) sections create rhythm
- **Photo-heavy cards** — Large images with gradient overlays and text at bottom
- **Pill buttons** — Fully rounded (`border-radius: 100px`) in dark or lime
- **Overline labels** — Small uppercase lime text above section headings
- **Logo marquee** — Scrolling brand logo bar in dark section
- **Stats sections** — Large bold numbers with small labels below
- **Generous whitespace** — Large section padding, airy layouts
