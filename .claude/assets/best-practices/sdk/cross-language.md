# Cross-Language Consistency

For every SDK language you ship, ensure these are consistent:

- [ ] Same resource hierarchy and method names (adapted to language conventions)
- [ ] Same error types and error codes
- [ ] Same pagination behavior
- [ ] Same retry/backoff defaults
- [ ] Same authentication patterns
- [ ] Same default timeout values
- [ ] Same User-Agent format: `{sdk-name}/{language}/{version}`
- [ ] Same CHANGELOG structure and release cadence
- [ ] Synchronized versioning (or clearly documented version mapping)
- [ ] Consistent README structure with quickstart examples
